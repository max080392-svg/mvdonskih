# Идиллия Вкуса

Адаптивный лендинг моти по предоставленному визуальному макету. HTML, CSS и JavaScript без зависимостей сборки.

## Запуск

Из каталога репозитория:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Для публикации достаточно любого хостинга статических сайтов. Включите HTTPS для работы копирования списка через Clipboard API.

## Что работает

Каталог шести вкусов, добавление отдельных десертов и набора в корзину, изменение количества, подсчёт суммы, сохранение корзины в браузере и копирование списка. Модальное окно поддерживает закрытие клавишей Escape. Макет адаптирован для мобильных экранов.

## Перед публикацией

Подтвердить цены, состав и аллергены; добавить реальные контакты, город, условия доставки и оплаты, юридические сведения и необходимые документы. Подключить канал отправки заказов. Сейчас список не отправляется продавцу и оплата не принимается. Отзывы не выдуманы: предусмотрен блок для будущих отзывов. Изображение `assets/mochi.png` сгенерировано для прототипа, замените фотографиями реальных десертов перед продажами.
